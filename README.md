# Currency Tracker

Консольное приложение для просмотра актуальных курсов валют и конвертации между рублями и иностранными валютами.

Курсы валют загружаются с сайта Центрального банка России через API.

## Возможности

* Просмотр текущих курсов USD, EUR и CNY
* Просмотр изменения курса относительно предыдущего значения
* Конвертация RUB → USD/EUR/CNY
* Конвертация USD/EUR/CNY → RUB
* Получение актуальных данных через API
* Простой консольный интерфейс

## Установка

Клонируйте репозиторий:

```bash
git clone <ссылка-на-репозиторий>
cd currency-tracker
```

Установите зависимость:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```
